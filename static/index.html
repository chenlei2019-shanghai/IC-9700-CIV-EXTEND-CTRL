🛰️ 卫星多普勒跟踪 未跟踪

纯软件双 VFO 多普勒跟踪（与 CSN S.A.T. 同思路）：不使用电台卫星模式，普通 VFO 模式下 MAIN = 上行(TX)、SUB = 下行(RX)，Dualwatch 双收，发射时可监听下行。
电台会自动设置：卫星模式 OFF / Dualwatch ON / SUB 发射静音 OFF（喇叭+USB+LAN）/ 双波段模式与亚音。
wfview 全双工 QSO：RX Codec 选 LPCM 2ch 16bit（立体声），MAIN/SUB 音频分别在左右声道； 用系统音量平衡只听 SUB 侧即是下行，PTT 从 MAIN 发射。

转发器配置

预设频率为转发器中心频率，过境前请对照 SatNOGS/AMSAT 核实；SSB 直线转发器在通联中沿通带微调即可。

⭐ 收藏与自动轮询
